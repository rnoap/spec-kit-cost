# All rates are standard-tier USD per million tokens (text modality).
# Cache columns (4-5) are optional — when absent, cache rates are derived as
# 0.10x (read) / 1.25x (write) of the resolved input rate (see catalog.sh).
# Audio/video/image-generation models are excluded — spec-kit is a text workflow.
#
# Sources (verified 2026-07-13):
#   Claude  — Wibey/Anthropic gateway rates (may differ from public Anthropic list prices)
#   OpenAI  — openai.com/api/pricing
#   Google  — ai.google.dev/pricing (≤200k context tier for Gemini models with tiered pricing)
#
# This extension works with any AI coding assistant (Wibey, GitHub Copilot, Cursor, etc.).
# The active model is detected from whichever context signal the host agent provides.
# Rate resolution — same FR-004 priority ladder in record-cost.sh and report-cost.sh.
# To add/update a model, edit this file only — no script changes required (FR-007).
#
# Matching rules (catalog.sh) — lookups are tolerant, so aliases are rarely needed:
#   1. Exact ID match.
#   2. Case/format-insensitive: "GPT-5.3-Codex" → gpt-5.3-codex; spaces → dashes.
#   3. Dots → dashes candidate: "Claude Sonnet 4.6" → claude-sonnet-4-6.
#   4. Dated/suffixed variants match their base ID by longest prefix:
#      claude-opus-4-8-20260220 → claude-opus-4-8.
